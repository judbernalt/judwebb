# JudWeb

## Short statement

this page was designed and developed by [nicolò Baldi](https://niente010.github.io/virtualscape/) for judith bernalt, VJ and multimedia artist.

the entire design revolves around the concept of the virtual interface as the perfect environment in which to play with the flexible and non-linear placement of elements.
in fact, the website is structured as a node-based 2D space through which visitors can navigate and occasionally personalize the visualization itself by displacing elements around. i was looking for a fluid and dynamic navigation, that would give the feeling of scraping a kind of database or archive by hunting for a specific information.

the aesthetic inspiration comes from the very detailed yet minimal graphics of operating systems for machines dedicated to scientific and (sadly) military purposes.
my visual references ended up almost uncosciously in this direction probably because i associated it to the highly visual and technical environment of a VJ. 

    just a quick consideration about this - even if we all the technologies we have are inherited from military research, that doesn’t mean their application should be used to support war, genocide or mass surveillance. so fuck all wars and all the tech investments that goes into them ^o^ 

btw, the whole collection of visual references can be found [here](https://www.are.na/nicolo-baldi/lord-forgive-me-im-nerdy-freaky).
